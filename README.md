# 🃏 Swipe Card Engine

A pure vanilla **HTML, CSS, and JavaScript** swipe card engine — no libraries,
no frameworks, no dependencies. Built iteratively across 14 versions, this
project demonstrates a fully interactive, Tinder-style draggable card stack
that works on both **desktop and mobile** devices.

---

## ✨ Features

- 👆 Drag-and-swipe interaction (left & right)
- 📱 Touch support for mobile devices
- 🎨 Smooth CSS transitions and rotation animations
- ♻️ Card stack management with DOM manipulation
- 🔁 Iterative version history (v0 → v13) showing progressive enhancements
- 🚫 Zero external dependencies — pure vanilla JS

## 🚀 Getting Started

No installation needed. Just clone or download the repo and open any HTML
file directly in your browser.

bash
git clone https://github.com/endritngjelina/Swipe-Card-Engine.git
cd Swipe-Card-Engine

open "Swipe Card Engine 13.html"
